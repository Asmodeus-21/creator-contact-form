# How to Add Real Profile Pictures

To replace the placeholder images with real Instagram profile pictures:

1. **Download Profile Pictures**:
   - Visit each influencer's Instagram profile
   - Right-click on their profile picture and save it
   - Name the files exactly as shown below

2. **Save to the correct folder**:
   - Place all images in: `public/influencers/`

3. **Required filenames**:
   - `maya.jpg` - Maya Saha (@ciaostardus) - Already added ✓
   - `fashioninflux.jpg` - Lydia Rose
   - `lillielexie.jpg` - Lillie Lexie
   - `thecuriouspixie.jpg` - Sima Sthanakiya
   - `aytanabbasli.jpg` - Aytan Abbasli
   - `julienfranks.jpg` - Julien Franks
   - `mikaylavallati.jpg` - Mikayla Vallati
   - `catieli.jpg` - Catherine Li

4. **Image specifications**:
   - Format: JPG or PNG
   - Recommended size: 200x200px (square)
   - The code will automatically crop/resize them to fit

5. **After adding images**:
   - The page will automatically update (hot reload)
   - If not, refresh the browser

**Note**: The code is already configured to use these local images. Just drop the files in the folder with the correct names!
